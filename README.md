# The old Flokefama WordPress website (archive)

A copy of the WordPress site that ran at flokefama.com until the new website went live (Nov 2026), saved from its
old server so it can be viewed any time. Plain files only (`site/`): no WordPress, so forms, the shop cart and
sign-in do nothing. Search engines are told not to index it.

Vercel builds this branch as its own preview: https://floke-fama-git-old-wordpress-site-jamesjnr1s-projects.vercel.app
